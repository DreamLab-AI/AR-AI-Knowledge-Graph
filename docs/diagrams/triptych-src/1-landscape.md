# Panel 1 — THE LANDSCAPE

**Subtitle:** The 5-repo sovereign ecosystem, held together by one identity spine.

## What this panel says
The DreamLab AI ecosystem is five interlocking open-source repositories. Each owns one
concern; `did:nostr` is the identity thread running through all of them. No central server,
no platform lock-in — sovereign data, sovereign keys, sovereign trust.

## The five repos (each drawn as a labelled card / building glyph)

1. **VisionClaw** — Knowledge engine. Oxigraph RDF + Whelk-rs OWL-EL reasoning,
   GPU physics, ~5,975 ontology classes, ACSP governance. The brain.
2. **agentbox** — Agent runtime. 88 skills, 5 LLM consultants, claude-flow swarm,
   per-turn ontology augmentation, governed 402-payment consumer. The hands.
3. **VisionFlow** — Coordination platform. The federated mesh where agents,
   human judgment, and institutional knowledge collaborate. The nervous system.
4. **solid-pod-rs** — Sovereign data substrate. HTTP 402 / WebLedger / MRC20 / AMM,
   git-marks + BIP-341 block-trails. The vault + ledger.
5. **nostr-rust-forum** — Governance & relay. Nostr relay mesh, ACSP decision
   surfaces, human sign-off. The town square.

## The identity spine (horizontal thread connecting all five)
- **did:nostr** identity everywhere — Schnorr / secp256k1 keys, NIP-98 HTTP auth,
  no passwords, W3C-compliant key rotation, NIP-26 delegation.
