state driven off the real `webSocketService` lifecycle, mirroring the
`onConnectionStatusChange` subscription already used at
`BotsWebSocketIntegration.ts:34` and `ConnectionWarning.tsx:27`. Initial state is
`isReady() ? 'connected' : 'connecting'`; the handler flips it to `'connected'` /
`'disconnected'` on real socket transitions. The prop is now
`websocketStatus={websocketStatus}`.
