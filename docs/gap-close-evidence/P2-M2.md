## What landed

### 1. Intervention panel (`scenes/HUD.tscn`, `scripts/hud.gd`)
- `HudControl/InterventionPanel` (hidden by default) with `CaseTitle`, `CaseSummary`, and Approve/Deny buttons.
- `show_case(case_id, summary)` reveals it; `clear_case()` hides it. Opened when a selected agent carries an open broker case (`graph_scene._on_selection_made` → `hud.show_case`).
- Approve → outcome `approve`; Deny → outcome `reject`. Both emit `decision_submitted(case_id, outcome)` immediately (the M2 intent, observable independent of the round-trip) and, when configured, POST the decision.

### 2. Signed decide POST — same route the desktop uses
- `configure_intervention(http_base, nostr_auth)` wires the HUD with the visionclaw-server origin and the Rust `NostrAuth` node.
- `_submit_decision` POSTs `{outcome, broker_pubkey, reasoning}` to `POST /api/broker/cases/{id}/decide` (`enrichment_proposals_handler::decide_as_operator`, the desktop operator route) via Godot's `HTTPRequest`, with an `Authorization: Nostr <base64(event)>` header minted Rust-side by `NostrAuth.nip98_header(url, "POST")`. The server accepts NIP-98 on the `power_user()` gate (`auth_extractor.rs:109`), so the headset authenticates against the same gate as the desktop and funnels through the same kernel + `broker:case_decided` core.
- **Transport deviation** recorded in ADR-130 ADR-trail (2026-07-08): the POST uses Godot `HTTPRequest` + a Rust-signed header rather than a new `reqwest` client in `transport.rs`; the secret never crosses the GDExtension boundary.

### 3. Ambient ACSP indicator + dwell reticle
- `AcspIndicator` (`AcspLabel` count + `AcspGlow` peripheral glow that pulses amber while cases are open). Driven by `set_case_count`, published from `graph_scene` on `set_agent_case` / `clear_agent_case` / `despawn_agent`.
- `DwellReticle` (`scripts/dwell_reticle.gd`) — a charging radial fed each frame from the Rust `SelectionArbiterNode.charge_ratio()` (Midas-touch mitigation, brief §4). Hidden at zero charge.

### 4. Rust surface addition (`xr-client/rust/src/signer.rs`)
- `NostrSigner::nip98_http_authorization(url, method)` → `Nostr <base64(event)>` (shares the event builder with the WS `authenticate` envelope).
- `NostrAuth` gdext node: `nip98_header(url, method)`, `pubkey_hex()`. Ephemeral fallback on empty/malformed secret (no crash; an ephemeral operator simply 401s server-side).
