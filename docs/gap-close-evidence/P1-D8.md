## What landed

- `client/src/features/bots/swarmObservability.ts` (pure): `computeSwarmSummary`
  aggregates the already-polled `BotsData` (agent count, active count, task
  success rate, cost = total tokens, mean health/workload, agent-type topology)
  and `extractMastFailureTags` surfaces MAST (Multi-Agent System failure
  Taxonomy) counts — top-level, per-metrics, or per-agent — returning `null` when
  absent so the panel **renders the row only when agentbox emits the fields and
  hides it otherwise** (WP-3 AC).
- `client/src/features/bots/components/SwarmObservabilityPanel.tsx`: renders the
  summary tiles, topology, MAST row (when present), the agent list
  (status/health/workload), and the `kg_backend_up` gauge + per-canary status
  fetched from `GET /api/canary/status` (RES-a harness). Fires
  `CANARY-VC-D8-OBS` once, when `hasLiveData` (a non-empty polled roster), via the
  new `client/src/services/livenessCanary.ts` fail-open observer.
- Mounted inside `AgentOpsSurface` (with `AgentDetailPanel`), wired into
  `MainLayout.tsx`. Reads bots data through a new non-throwing
  `useBotsDataOptional` accessor so the surface degrades to empty rather than
  crashing outside a provider.
- Canary seed: `CANARY_D8_OBS` added to `P1_CANARIES`
  (`src/services/liveness_harness.rs`).

## Falsification (PRD-023 WP-3, D8 half) → how it is met

*"…or if D8 closes on a dead `HealthDashboard` that no route mounts."*

- The dashboard that mounts is `SwarmObservabilityPanel` — a fresh component
  reading the live `BotsDataContext` poll and the live canary status, mounted via
  `AgentOpsSurface` → `MainLayout`. The dead `HealthDashboard` / `SystemHealthPanel`
  / `ActivityLogPanel` are deliberately NOT used; a grep confirms they remain
  unimported. The panel is distinct from `AgentTelemetryStream` (a per-message
  log) — it is a swarm-level aggregate.

## Honest residual (pending-live-session)

`CANARY-VC-D8-OBS` is one-shot and `armed`: the real fire is written when a
running client mounts the panel with a live agent roster and its
`observeCanary('CANARY-VC-D8-OBS', …)` call reaches the harness. The aggregation
maths and the MAST extraction are unit-proven; the mount-time observe is
compile-verified and gated on live poll data, not exercised end-to-end here.
