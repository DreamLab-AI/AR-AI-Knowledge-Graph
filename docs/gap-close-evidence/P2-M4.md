## What landed (`xr-client/rust/src/`)

### 1. `gaze.rs` — unified head/eye gaze ray with one-euro smoothing
- `GazeSource::{Head, Eye}` behind one `GazeRay { origin, dir, source }`. **Head-gaze primary**; eye-gaze is a progressive enhancement gated on a runtime flag: `GazeResolver::set_eye_gaze_supported(bool)` (fed from `OpenXRInterface.is_eye_gaze_interaction_supported()`, called only after OpenXR init). `effective_source(Eye)` degrades to `Head` unless supported, so the Quest-3 floor device never selects eye-gaze.
- `OneEuroFilter` (Casiez et al. 2012) implemented from scratch: adaptive cutoff `min_cutoff + beta·|edx|`, `alpha = 1/(1+tau/dt)`. First sample passes through; non-positive `dt` holds the last value (no divide-by-zero on shared timestamps).
- Property/convergence tests: `converges_to_constant_input` (500 constant samples → within 1e-3), `output_never_overshoots_input_range` (low-pass output stays inside the running [min,max] — no ringing), `smoothing_reduces_direction_jitter` (angular error to the mean is strictly lower than the raw samples'), `zero_dt_holds_last_value`, `resolved_dir_is_unit_length`.

### 2. `selection.rs` — three resolvers → one arbiter → one `SelectionEvent`
- `SelectionEvent { target_entity: u32, did_nostr: Option<String>, resolver, timestamp_us }`.
- **Resolver 1 (controller ray)** and **Resolver 2 (pinch)** both feed the *existing* `interaction.rs` path: `find_target` for the corridor test, `is_grab_active` for pinch. Explicit selection fires on the **rising edge** of the trigger (`ControllerRay`) or of the pinch (`Pinch`) — a held trigger does not repeat (`trigger_hold_does_not_repeat`).
- **Resolver 3 (gaze dwell)**: `DwellCharger` charges a target over a **600 ms default within a configurable 400–800 ms band**, with a **target-size floor** (`target_radius_floor_m`, small nodes get a minimum acquisition radius), **activation hysteresis** (a charging target is kept while within `hysteresis_factor×` its radius), and **cancel-on-saccade** (charge resets when gaze angular velocity exceeds `saccade_cancel_rad_s`). `charge_ratio()` drives the radial reticle fill (Midas-touch mitigation from the brief). It fires once per dwell (`fired_latch`).
- **Arbitration priority**: explicit trigger/pinch **beats** dwell (`explicit_click_beats_dwell` — the dwell resets when an explicit pick lands). Dwell **only arms** when no controller is tracked (`dwell_fires_when_no_controller`) **or** `hands_free` is set (`dwell_arms_in_hands_free_even_with_controller`); a tracked controller with no hands-free flag disables the charger entirely (`dwell_disabled_while_controller_tracked`).
- **Non-origin selection**: the ray origin is the caller-supplied controller/gaze origin (never a hard-coded `[0,0,0]`); candidates are real node positions. `controller_trigger_click_selects_and_carries_did` resolves node 7 at `[0,0,-5]` with its DID.

### 3. `did:nostr` carry + the named server-side integration point
- `SelectionArbiter::register_identity(node_id, did_nostr)` fills a `HashMap<u32,String>`; a resolved event's `did_nostr = registry.get(target)` (`None` when the entity has no DID yet — an honest absence, `no_did_yields_none_did_field`).
- The 0x03 graph binary record (fixed 52 bytes) has no room for a 32-byte pubkey, so identity rides the `initialGraphLoad` node metadata instead. **Additive extension landed HERE**: `binary_protocol::parse_agent_identities(text)` reads an optional `did_nostr`/`didNostr` per node (id masked with `NODE_ID_MASK`) and returns `(node_id, did)` pairs (`parse_agent_identities_extracts_did_and_masks_flags`).
  - **Named integration point (server-side emit):** the VisionClaw graph server must include `did_nostr` on each agent node in the `initialGraphLoad` payload, sourced from the agent record's `did_nostr` field landed by COM-14 P0 (`src/services/bots_client.rs` / `agent_visualization_protocol.rs`). Until it does, `parse_agent_identities` returns empty and selections carry `None` — no fabricated identity. GDScript wires the parser output into `SelectionArbiterNode::register_identity` (Stage 2 glue).

### 4. GDScript-facing nodes (compile-verified, `cfg(not(test))`)
`GazeTracker` (resolve / set_eye_gaze_supported), `SelectionArbiterNode` (begin_frame / push_controller / set_candidates / set_gaze / tick → `selection_made(node_id, did_nostr, resolver)` / charge_ratio). Auto-registered via the `#[gdextension]` `ExtensionLibrary`.
